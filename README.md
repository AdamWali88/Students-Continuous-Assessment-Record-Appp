GitHub Pages deployment package for the offline PWA.

**Important:** Student records are stored in the browser's local storage. Before moving from the old Netlify address to this GitHub Pages address, use **Settings → Data Management → Export Backup** in the existing app. After opening the new GitHub Pages app, use **Settings → Data Management → Import Backup**.
